## 数据集概述

本数据集专注于**无人机航拍视角下的古建筑缺陷检测与实例分割**，服务于古建筑普查、老旧房屋损毁检测及文物保护遥感AI识别。数据涵盖七类建筑及环境目标，适配航拍实例分割算法训练、文物状态评估及古村落保护规划等应用。

## 数据三要素解析

**类别与目标覆盖**
*   数据集定义 **7** 类古建筑及环境目标，覆盖 **建筑结构类**（屋顶轮廓、整体损毁建筑）、**损毁类**（坍塌孔洞、瓦片破损、木材裸露）及 **环境类**（植被、现代遮盖物）。
*   类别设置兼顾了完好建筑识别与损毁特征检测，服务于古建筑状态综合评估。
*   图像从高空视角拍摄古村落建筑群，包含多种古建筑状态。

## 知识普及：古建筑航拍实例分割的技术要点

*   **形态复杂**：古建筑屋顶、瓦片、木构件等目标形态复杂，边缘不规则，需模型具备较强的边缘保持能力。
*   **类别相似性**：坍塌孔洞与木材裸露、瓦片破损与整体损毁建筑在视觉上可能相近，模型需依赖位置、形态与纹理特征进行区分。
*   **植被遮挡**：古建筑常被植被覆盖或遮挡，影响目标识别，需采用多尺度特征融合策略。
*   **光照与角度**：航拍角度、光照条件变化大，建议训练时加入亮度、对比度增强与视角变换。
*   **实例分割优势**：相比目标检测（边界框），实例分割能精确勾勒古建筑构件轮廓，支持面积、周长等几何参数计算，对文物状态量化评估至关重要。
*   **应用闭环**：分割结果可导入文物保护GIS系统，结合历史影像进行损毁趋势分析，辅助修缮规划与保护决策。

## 快速开始（代码示例）

**1. 准备配置文件 (`dataset.yaml`)**
```yaml
path: ./dataset
train: images/train
val: images/val
test: images/test
nc: 7
names: ['植被', '坍塌孔洞', '现代遮盖物', '屋顶轮廓', '瓦片破损', '整体损毁建筑', '木材裸露']
```

**2. 启动 YOLOv11n-seg 训练**
```python
from ultralytics import YOLO

model = YOLO("yolo11n-seg.pt")
results = model.train(
    data="dataset.yaml",
    epochs=200,
    imgsz=640,
    batch=16,
    device=0
)
```
